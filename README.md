# CSS Projects Collection

A collection of modern CSS projects showcasing web design and frontend development skills.

## Projects

### 1. **Airbnb Clone** 
- **Folder:** `airbnb/`
- **Files:** `air.html`, `bnb.css`
- **Description:** Airbnb-inspired landing page with responsive design

### 2. **Apple Homepage Clone**
- **Folder:** `Apple/`
- **Files:** `index.html`, `style.css`
- **Description:** Apple's official website recreation with modern CSS styling

### 3. **Google Homepage**
- **Folder:** `GoogleHomePage/`
- **Files:** `index.html`, `style.css`
- **Description:** Google search page clone with minimalist design

### 4. **Instagram Login Page**
- **Folder:** `Insta login page/`
- **Files:** `insta.html`, `gram.css`
- **Description:** Instagram login page replica with form styling

### 5. **Spotify Clone**
- **Folder:** `spotifypage/`
- **Files:** `spot.html`, `kd.html`, `tify.css`
- **Description:** Spotify music streaming interface design

### 6. **YouTube Clone**
- **Folder:** `Youtubeclone/`
- **Files:** `youtube.html`, `clone.css`
- **Description:** YouTube video platform interface replica

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Anshulsaini0/CSS-Projects.git
cd CSS-Projects
```

2. Open any project in your browser by opening the HTML files directly
